Getting Started with Elementor

A playful step-by-step guide for beginners

1. Install the Plugin

From your WordPress Dashboard, go to Plugins → Add New. Search “Elementor”, then click Install → Activate.

2. Create Your First Page

Go to Pages → Add New → Name it → Click “Edit with Elementor”.

3. Play with Widgets

Use drag & drop to add Headings, Text, and Images to your layout. Try moving them around!

Sweet Tip

Use Elementor’s Templates to get a headstart — just import and tweak them your way!

4. Preview & Publish

Click the Preview icon to test on mobile/desktop. Then hit “Publish” to make it live!
